# JAY DISTRIBUTION MACHINE V0.1

Purpose: turn verified creative artifacts into repeatable distribution work while keeping the human operator rested.

## Roles
- J: laborer / signer / publisher / live human judgment.
- OpenAI worker: reads state, proposes ranked next actions, drafts copy, summarizes metrics, and prepares the daily dispatch.
- GitHub: directory contract, manifests, receipts, machine-readable state.
- Google Drive: human asset warehouse and working documents.
- Gmail: morning work order and outreach transport.

## Money Loop
ARTIFACT -> PACKAGE -> DISTRIBUTE -> OBSERVE -> MEASURE -> FOLLOW UP -> REUSE

Revenue is an outcome to measure, not a guaranteed state. Never manufacture volume, fake holders, or self-trade for appearance.

## Human Sleep Rule
The machine may organize, draft, measure, and prepare queues while J is offline. Wallet signatures, publishing, spending, trading, and irreversible external actions remain J-controlled unless separately authorized.

## Daily Output
Every morning produce a short work order containing:
1. Money opportunities first.
2. Distribution actions with the highest expected payoff.
3. Replies/follow-ups that require J.
4. One build/automation task.
5. HOLD items and risks.
6. A stop time so J can leave the machine.
