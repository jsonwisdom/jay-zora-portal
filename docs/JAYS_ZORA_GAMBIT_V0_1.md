## Scale law

At 1000+ public posts, manual one-object-at-a-time interpretation is not the operating model.

```text
ENUMERATE
→ BATCH
→ OBSERVE
→ HASH
→ COMPARE
→ ROUTE
→ REPORT JSONL
→ PROMOTE EXPLICITLY
```

A batch may contain many observations, but each object preserves its own identity, source timestamps, hashes, comparison state, and disposition.
